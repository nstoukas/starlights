# content-manager

## Overview

A placeholder for the future content management app (for now a single page in `App.tsx`). Aspire runs it as `app-content-manager`.

## Stack

- React 19, Tailwind 4, Vite 8, TypeScript 7, Prettier
- Uses `ui-framework`

## Commands

```bash
# from src/frontend
npm run dev -w apps/content-manager
npm run build -w apps/content-manager
npm run typecheck -w apps/content-manager
npm run format -w apps/content-manager
```

Shared frontend conventions live in [src/frontend/AGENTS.md](../../AGENTS.md). Run `/audit src/frontend/apps/content-manager` for a deeper scan of this workspace.
