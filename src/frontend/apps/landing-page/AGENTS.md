# landing-page

## Overview

A placeholder for the public landing page (for now a single page in `App.tsx`). Aspire runs it as `app-landing-page`.

## Stack

- React 19, Tailwind 4, Vite 8, TypeScript 7, Prettier
- Uses `ui-framework`

## Commands

```bash
# from src/frontend
npm run dev -w apps/landing-page
npm run build -w apps/landing-page
npm run typecheck -w apps/landing-page
npm run format -w apps/landing-page
```

Shared frontend conventions live in [src/frontend/AGENTS.md](../../AGENTS.md). Run `/audit src/frontend/apps/landing-page` for a deeper scan of this workspace.
