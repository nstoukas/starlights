# showcase

## Overview

A gallery for the `ui-framework` component library; each demo lives in `src/showcases/`. Aspire runs it as `app-showcase`.

## Stack

- React 19, Recharts, react-qr-code, Tailwind 4, Vite 8, TypeScript 7, Prettier
- Uses `ui-framework`

## Commands

```bash
# from src/frontend
npm run dev -w apps/showcase
npm run build -w apps/showcase
npm run typecheck -w apps/showcase
npm run format -w apps/showcase
```

Shared frontend conventions live in [src/frontend/AGENTS.md](../../AGENTS.md). Run `/audit src/frontend/apps/showcase` for a deeper scan of this workspace.
